Exploratory Data Analysis & System Architecture

MASARI's intelligence dashboard is powered by a robust backend pipeline that transforms unstructured educational data into highly tailored, actionable learning paths. Explore the four foundational pillars of our system below.

1. Data Processing Pipeline

We aggregate millions of data points from premier platforms (Coursera, EdX, Udemy). Our ingestion engine applies strict descriptive heuristics and NLP filtering to eliminate noise, ensuring only high-quality Computer Science curricula enter our primary MongoDB repository.

2. TF-IDF IR Framework

Queries are vectorized using a mathematical TF-IDF Vector Space Model. We compute Cosine Similarity coefficients across our entire corpus in real-time, matching student intents to highly relevant course syllables with extreme precision.

3. Neural Embeddings Graph

Course relationships are modeled using pairwise similarity vectors. This maps out organic learning ecosystems (e.g., how Python transitions into Machine Learning).

4. LLM Study Orchestrator

Powered by Llama 4 Scout, our orchestrator acts as a virtual academic advisor. It synthesizes IR search results with user career goals to automatically generate week-by-week, personalized syllabi containing practical labs and milestones.
